# Definition of done

- [ ] Requisito atendido e comportamento existente preservado.
- [ ] Código equivalente foi pesquisado antes de novas estruturas.
- [ ] Risk gate foi classificado e, para MEDIUM/HIGH, houve plano.
- [ ] Autenticação, autorização, tenant e IDOR foram analisados.
- [ ] Segurança e LGPD foram revisadas quando aplicável.
- [ ] Dados sensíveis e segredos não foram expostos.
- [ ] Integrações externas tratam falhas e mantêm contrato real.
- [ ] Testes relevantes foram executados sem depender de produção.
- [ ] Build/lint foram validados quando aplicável.
- [ ] `git diff --check` passou e o diff foi revisado.
- [ ] Arquivos, riscos, decisões e `NEEDS_VERIFICATION` foram relatados.
